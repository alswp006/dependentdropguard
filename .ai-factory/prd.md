# DependentDropGuard

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
부업·N잡 소득이 늘어날 때 건강보험 피부양자 자격을 유지할 수 있는지 매달 진단해주는 앱

## Problem
N잡·부업이 늘면서 소득이 일정 기준(연 2,000만원 등)을 넘으면 건강보험 피부양자 자격을 잃고 지역가입자로 전환되어 보험료 폭탄을 맞는 경우가 많은데, 이를 미리 확인할 방법이 마땅치 않다.

## Target Users
직장 다니며 부업·프리랜서 소득이 있는 20~40대 N잡러

## Core Features
1. 본업+부업 소득 합산 입력
2. 피부양자 자격 유지/탈락 여부 즉시 진단
3. 탈락 시 예상 건강보험료 계산
4. 매달 소득 변동 추적 및 알림
5. 지역가입자 전환 시뮬레이션
6. 진단 결과 리워드 광고 후 상세 리포트 공개

## Monetization
- Model: ads
- Estimated MRR: 64
- Reasoning: 부업 소득은 매달 변동되므로 정기적으로 재방문할 유인이 있고, '자격 탈락 위험' 진단이라는 불안 요소가 리워드 광고 시청 전환율을 높인다. N잡 트렌드와 맞물려 다른 계산기 대비 반복 사용 가능성이 높다.
